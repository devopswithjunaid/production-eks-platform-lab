# Production EKS Platform Lab

A long-running DevOps and Platform Engineering project for designing,
building, securing, operating and troubleshooting a production-style
microservices platform on Amazon EKS.

## Technology Stack

- AWS
- Amazon EKS
- Terraform
- Docker
- Kubernetes
- GitHub Actions
- Amazon ECR
- Argo CD
- HashiCorp Vault
- Prometheus
- Grafana
- OpenTelemetry
- Loki
- Tempo

## Engineering Areas

This project focuses on:

- Infrastructure as Code
- Kubernetes
- CI/CD
- GitOps
- Cloud Security
- Kubernetes Security
- Secrets Management
- Networking
- Observability
- Reliability Engineering
- Incident Response
- Troubleshooting
